# IntelliJ-Servlet-Example
Esercizio di introduzione alle servlet utilizzando intelliJ comunity edition

## Tecnologie
- Java 21
- Apache Tomcat 10.1.x
- Servlet API 6.0 (Jakarta EE)
- IntelliJ IDEA (Community Edition)

## Prerequisiti
- JDK 21
- Tomcat 10.1+ ([Download](https://tomcat.apache.org/))
- Maven (opzionale)
